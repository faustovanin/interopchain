# Hyperledger Fabric Docker Configuration

This directory contains the Docker Compose configuration for the Hyperledger Fabric network used by Interopchain.

## Components

- **Peers** — endorsing and committing peers for each organisation.
- **Orderers** — ordering service nodes (Raft consensus).
- **Certificate Authorities (CAs)** — one CA per organisation for issuing identities.

## Usage

Start the Fabric network using the development script:

```bash
./scripts/start-dev.sh
```

Or bring it up directly:

```bash
docker compose -f docker/fabric/docker-compose.fabric.yml up -d
```

## Configuration

Network configuration (channel artifacts, crypto material) is generated by the setup script:

```bash
./scripts/setup.sh
```

Refer to the [Hyperledger Fabric documentation](https://hyperledger-fabric.readthedocs.io/) for details on peer, orderer, and CA configuration parameters.
